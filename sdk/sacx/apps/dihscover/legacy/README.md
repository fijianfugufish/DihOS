# Legacy Dihscover renderer

This directory preserves Dihscover's original hand-written browser engine as a
historical reference. It includes the local DOM, HTML recovery, CSS/layout,
JavaScript compatibility bridge, URL handling, and the old SACX shell.

Nothing in this directory is compiled by the active Dihscover build. Do not add
these files back to `../build.ps1`; the active implementation is the NetSurf
front end in the parent directory.
